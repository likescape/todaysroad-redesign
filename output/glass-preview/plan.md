# 오늘의길 다크·라이트 Glass 디자인 적용

## 적용 방향과 구현체

기존 배치와 기능을 유지하면서 앱 전체의 주요 표면에 **반투명·블러·빛나는 테두리와 은은한 굴절**을 적용합니다. 초록색 브랜드와 모드별 로고는 유지합니다.

**React Bits의 `GlassSurface` TypeScript + CSS 구현을 채택합니다.** 추가 런타임 의존성이 없어 현재 Next.js 15·React 19·일반 CSS 구조에 통합하기 좋으며, 기존 Motion 애니메이션을 그대로 활용할 수 있습니다. [GitHub 소스](https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/GlassSurface)

비교한 `fluidkit`은 React·Motion 의존성 조건이 맞지만 초기 프로젝트이고, `liquid-glass-react`는 굴절 중심의 단일 효과 컴포넌트입니다. 이번에는 기존 UI를 유지하며 재질을 공통화하기 쉬운 React Bits를 선택합니다. [fluidkit](https://github.com/runvendo/fluidkit), [liquid-glass-react](https://github.com/rdev/liquid-glass-react)

## 디자인 시스템과 적용 범위

`app/globals.css`의 기존 테마 변수에 유리 전용 색상·불투명도·블러·테두리·그림자 토큰을 추가합니다.

| 재질 | 적용 대상 | 초기 기준 |
|---|---|---|
| `clear` | 로고·현재 위치·설정 버튼, 하단 탐색 | 블러 16px, 밝은/어두운 모드 불투명도 62%/64% |
| `regular` | 추천 패널, 코스 카드, 산책 수치, 일반 카드 | 블러 20px, 불투명도 76%/80% |
| `dense` | 이야기 상세, 대화상자, 작성·입력 영역 | 블러 24px, 불투명도 90%/92% |

- 홈·코스·산책·스팟·커뮤니티·내 산책·설정에 동일한 재질 규칙을 적용합니다. 화면 모드 선택 미리보기도 함께 갱신합니다.
- 지도 외 화면에는 낮은 대비의 정적인 녹색 배경 그라데이션을 더해 유리 표면의 깊이를 표현합니다.
- 주요 실행 버튼은 초록색 강조를 유지하고, 선택·비활성·위험 상태를 명확히 구분합니다.
- 본문·사진·아이콘은 선명하게 유지합니다. 카드 안의 중첩 컨트롤에는 별도의 강한 블러를 겹치지 않습니다.
- 지도 타일·경로·마커의 기능은 유지하고, 마커 표면은 CSS 재질만 조정합니다.

## 구현과 인터페이스

- React Bits 소스를 커밋 `4bb4491b3879b115eb6758fae7f5b6c3ec7eb0a3` 기준으로 가져와 프로젝트 내부 공통 컴포넌트로 관리합니다. 원본 출처·변경 내역·라이선스 고지를 보존합니다. 라이선스는 MIT + Commons Clause입니다. [라이선스](https://github.com/DavidHDev/react-bits/blob/4bb4491b3879b115eb6758fae7f5b6c3ec7eb0a3/LICENSE.md)
- 공통 `GlassSurface`는 `variant`, `refraction`, `as`, 표준 DOM 속성과 `ref`를 지원합니다. CSS만 필요한 기존 요소는 `data-glass="clear|regular|dense"`로 같은 토큰을 사용합니다.
- 원본의 고정 크기·가운데 정렬·시스템 테마 전용 규칙을 제거하고 기존 요소의 크기·배치와 `html[data-theme]`를 따르게 합니다. 기존 `ThemeProvider`와 저장 설정을 계속 사용합니다.
- 굴절은 배경 장식 레이어에만 적용합니다. 기본값은 꺼짐이며, 데스크톱 Chromium의 하단 탐색·로고·현재 위치 버튼에서만 활성화합니다. 모바일·Safari·Firefox에서는 같은 색상과 테두리를 가진 블러 재질을 사용합니다.
- 기존 Motion의 `layoutId`, 스프링, 클릭 동작을 보존합니다. 크기 측정은 변형 전 레이아웃 치수를 사용해 데스크톱 축소 화면에서도 굴절이 어긋나지 않게 합니다.
- 블러 미지원·투명도 감소·강제 색상 환경에서는 불투명 표면을 제공합니다. 모션 감소 설정에서는 굴절과 추가 장식 움직임을 끕니다.
- 새 테마 저장소·백엔드 API·데이터 변경은 추가하지 않습니다. 현재 작업 중인 변경사항을 기준으로 통합하며 배포는 이번 범위에 포함하지 않습니다.

## 검증과 완료 기준

현재 기준선인 `npm test` **28개가 모두 통과**했습니다. 구현 후 다음을 확인합니다.

- `npm test`, `npm run build` 통과 및 브라우저 런타임·hydration 오류 없음.
- 기기 모드와 반대로 수동 테마를 선택한 경우, 새로고침·다른 탭에서도 모든 유리 표면이 선택한 모드를 유지.
- 양쪽 테마에서 홈→추천→코스→산책→종료, 스팟 상세, 커뮤니티 작성, 내 산책, 설정 흐름 확인.
- 390×844, 320×640 모바일과 일반·축소 데스크톱에서 잘림·버튼 겹침·스크롤 회귀 없음.
- Chromium·WebKit·Firefox에서 유리 표현과 대체 표면 확인. 키보드 포커스, 대화상자 Escape·포커스 복귀, 지도 드래그 유지.
- 지도 이동과 패널 전환 중 체감 성능 저하가 없고, 테마 전환 시 지도 인스턴스·산책 타이머·작성 내용 유지.
- 주요 화면의 다크·라이트 스크린샷을 비교해 본문 대비 4.5:1을 확보하고, 필요하면 해당 재질의 불투명도를 높여 조정.
