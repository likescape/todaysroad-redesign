# 실제 지도 기반 7단계 실행 기록

- 실행일: 2026-09-09
- 화면: http://localhost:8000/dev/image-route
- 지도: 실제 카카오맵, 부산시민공원 주변, 레벨 3, 1024×1024 픽셀
- 분석: 로컬 Codex CLI의 기존 ChatGPT 로그인 사용. 별도 OpenAI API 키 없이 실행.
- 참고 문서에서는 1~7단계의 절차만 사용했으며, 예시 지도·추론·결론을 분석 데이터로 사용하지 않았다.

## 실행 결과

1. 실제 지도 캡처: [busan-source.png](busan-source.png)
2. 이미지에서 길 39개와 주변 지물 11개 인식
3. 산책 시간 15분, 자연·도시 취향 적용
4. 길 유형·신뢰도·연결 관계와 지물 분류를 이용해 후보 필터링
5. 경유지 2곳 선택
6. 인식된 길의 연결 관계로 출발점에 돌아오는 경로 생성
7. 계산 거리 1,132.83m, 예상 시간 17분

최초 테스트 좌표는 잔디광장 안에 있어 인식된 길에서 약 88m 떨어졌고, 기존 60m 제한에 따라 경로 생성이 중단됐다. 화면의 명시적인 테스트 출발점 선택 기능으로 가까운 인식 도로 위를 선택한 뒤 3~7단계를 다시 실행했다. 최종 출발 좌표는 위도 35.16881345295853, 경도 129.05852735375314다. GPS 현재 위치의 거리 제한은 유지된다.

전체 분류·좌표·필터링 기록·최종 경로는 [busan-analysis.json](busan-analysis.json)에 저장했다. 이 경로는 지도 이미지 해석으로 만든 초안이며, 실제 현장의 통행 가능 여부나 지도 선형의 정밀도를 검증한 결과는 아니다.
