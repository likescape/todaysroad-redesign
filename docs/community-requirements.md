# 커뮤니티 기능 범위

## 현재 구현
- 기존 잎 테마를 확장해 공개 피드, 내 이야기, 글 상세, 작성·수정·삭제 화면을 연결한다.
- 산책 종료 시 경로·거리·시간을 바로 저장하고 완료 화면에서 이야기 작성 또는 내 산책 복귀를 제공한다. 기존 내 산책 목록의 UI는 유지한다.
- 내 산책의 기록 상세는 경로·거리·시간·페이스·시각 중심의 요약이다. 별도의 일기·기분·사진 입력 및 기록 수정 화면을 제거한다.
- 기록 상세의 ‘이 산책에 이야기 남기기’와 커뮤니티의 ‘이야기 쓰기’는 동일한 작성·저장 흐름을 사용한다. 기록에서 시작하면 해당 코스를 자동 첨부한다.
- 본문, 사진 최대 5장, 별도 코스 첨부(경로 좌표·거리·시간)를 지원한다. 코스 없이 사진·본문만 작성할 수 있다.
- JPG·PNG·WebP 사진을 이야기 작성 화면에서 첨부한다. 사진은 한 장당 최대 10MB이며 저장 전에 크기를 줄인다. 이전 버전에서 기록에 저장한 메모·사진은 보존하고 이야기 작성 시 가져올 수 있다. 새 글·사진은 게시글에만 저장한다.
- 전체 공개와 나만 보기를 선택한다. 기록에서 시작하면 나만 보기, 커뮤니티에서 새로 작성하면 전체 공개가 기본값이며, 글 수정 시 기존 값을 유지한다. 공개 피드는 전체 공개 글만, 내 이야기는 본인의 공개·비공개 글을 표시한다. 비공개 저장 후 커뮤니티 진입 시 내 이야기를 선택한다.
- 본인 글만 수정·삭제 버튼을 표시하며 데이터 변경 함수에서도 작성자를 검사한다.
- 예시 글과 기기 내 작성 글을 최신순으로 표시하고, 3개씩 더 불러온다. 로딩·빈 목록·저장 실패·사진 처리 실패 상태를 제공한다.
- 팔로우 버튼, 팔로워·팔로잉 수, 팔로잉 피드를 제공하지 않는다.
- 프런트엔드 목업이다. 기록·게시글·사진은 브라우저 localStorage에 저장하며 실제 서버 저장·인증·업로드·다른 사용자와의 동기화는 구현하지 않는다. 실제 공개 게시가 이루어지는 것은 아니다.

## 서버 연동 시 기능 기준
- 다른 사용자들이 공개한 산책 기록을 조회하는 피드 제공.
- 글 작성·조회·수정·삭제. 수정과 삭제는 작성자 본인만 가능.
- 기록에는 본문, 사진, 산책 코스를 함께 첨부할 수 있음.
- 글·사진은 공통 이야기 작성 화면에서 저장하며, 산책 기록에서는 코스를 첨부해 작성 화면으로 진입함.
- 코스는 경로 좌표, 거리, 소요 시간 등을 포함하는 별도 첨부 데이터로 표현.
- 팔로워·팔로잉 및 이를 기반으로 한 피드는 제공하지 않음.
- 실제 구현 시 공개 범위, 사진 업로드, 작성자 권한, 목록 페이지네이션 및 실패/빈 상태를 처리.

## 후속 검수
- 산책 종료 후 별도 일기 저장 없이 기록이 남고, 이야기 작성을 취소해도 기록이 유지된다.
- 기록에서 시작한 이야기는 코스가 첨부되고 나만 보기가 선택되어 있으며, 기존 메모·사진도 유실되지 않는다.
- 타인의 공개 글 조회, 본인의 글 작성/수정/삭제가 가능하다.
- 사진과 코스 첨부 내용이 저장 후 조회에서도 유지된다.
- 다른 사용자의 글을 수정/삭제할 수 없다.
- 팔로우 버튼과 팔로워/팔로잉 수가 노출되지 않는다.
