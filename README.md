# 오늘의길

오늘 걷기 좋은 길을 추천해주는 산책 코스 앱 (Next.js + Kakao Map).

## 실행

```bash
npm install
npm run dev
```

→ http://localhost:8000

> 기본 실행 포트는 **8000**이며 로컬 인터페이스에만 연결합니다.
> 카카오 개발자 콘솔의 Web 도메인에 `http://localhost:8000`을 등록하세요.

## 환경 변수

`.env.local`

```
NEXT_PUBLIC_KAKAO_MAP_KEY=<카카오 JavaScript 키>
```

## 화면 모드

- 처음에는 휴대폰·브라우저의 `prefers-color-scheme`을 따릅니다. 실행 중 기기 모드가 바뀌어도 즉시 반영됩니다.
- **설정 → 화면 모드**에서 라이트·다크를 직접 선택하거나 **기기 설정 따르기**를 켤 수 있습니다. 직접 선택하면 기기 연동이 꺼집니다.
- 선택은 `localStorage`의 `todaysroad-theme`에 저장되며 새로고침·재방문·같은 출처의 다른 탭에도 적용됩니다. 저장소가 차단되어도 현재 세션의 전환은 동작합니다.
- 첫 화면이 밝게 깜빡이지 않도록 React 실행 전에 테마를 적용합니다. 다크 모드에서는 첨부한 흑백 로고(`leaf-logo-dark.png`)를 앱 내부와 파비콘에 사용합니다. 이 웹 목업은 OS 홈 화면에 설치한 네이티브 앱 아이콘을 변경하지 않습니다.
- 지도·마커·경로, 추천 패널, 하단 탭, 내 산책, 커뮤니티, 글쓰기 및 대화상자가 같은 테마를 공유합니다. 산책 중 전환해도 지도 인스턴스와 위치·진행 상태는 유지됩니다.
- **지도 제한:** 현재 사용하는 카카오 지도 Web SDK에는 공식 다크 지도 타입이 없습니다([Web API 문서](https://apis.map.kakao.com/web/documentation/#MapTypeId), [카카오 공식 답변](https://devtalk.kakao.com/t/api/129687)). 목업의 다크 지도는 기본 타일 이미지에만 CSS 색상 보정을 적용합니다. 마커·경로·사진·카카오 저작권 표시는 필터에서 제외하며, 네이티브 다크 지도를 연결한 구현은 아닙니다.
- 테마 상태는 `components/ThemeProvider.tsx`, 초기 적용은 `lib/theme.ts`, 색상은 `app/globals.css`의 공통 변수에서 관리합니다. `npm test`로 저장값 우선순위·첫 화면 테마·저장소 차단 시 동작과 기존 산책 기록을 검사합니다.

## 인터랙션

- 하단 '코스 생성' 버튼을 누르면 밝은 추천 패널이 스프링으로 확장되고, 닫으면 다시 버튼으로 줄어듭니다
  (`motion`의 shared `layoutId` + `AnimatePresence`).
- 설정은 홈 우상단 또는 내 산책에서 별도 화면으로 열며, 알림 토글은 설정 안에 있습니다.
- '오늘의길' 버튼은 어떤 상태에서도 유지되며 클릭 시 패널·시트를 닫고 지도를 초기 위치로 되돌립니다.
- 스크림 클릭 또는 `Esc`로도 패널을 닫을 수 있습니다.

지도는 드래그 이동, 휠/핀치 제스처 확대·축소가 가능합니다.
추천 코스 말풍선 마커를 클릭하면 하단에 코스 설명 시트가 열리고,
지도 빈 곳을 클릭하면 닫힙니다.


## 밝은 잎 테마 리디자인

- 제공받은 잎 로고 원본을 `public/assets/leaf-logo.png`에서 사용합니다.
- 홈의 지도/코스 생성, 하단 홈·커뮤니티·마이 탭, 마이 → 설정 → 뒤로 가기를 연결했습니다.
- 마이의 기존 산책 통계·예시 기록 UI는 유지하며, 새로 완료한 산책을 통계와 목록에 더합니다.
- 계정 연결, 계정 관리, 약관은 준비 안내 화면이며 실제 계정 변경은 실행하지 않습니다.
- 설정의 알림 토글은 세션 내 미리보기이며 실제 발송/서버 저장 기능은 없습니다.
- 커뮤니티의 현재 구현 범위는 아래 ‘산책 기록과 커뮤니티’를 참고하세요. 실제 백엔드는 구현 범위에서 제외합니다.
- 공유 기능 요구사항은 [커뮤니티 기능 범위](docs/community-requirements.md)를 참고하세요.


## 상단 탐색 실험 (`experiment/top-navigation`)

- 기존 하단 탭 버전은 `design/leaf-bottom-nav` 브랜치에 보존했습니다.
- 홈 오른쪽 위: 커뮤니티 / 내 산책 (아이콘 + 작은 라벨).
- 홈 아래: 코스 생성 / 현재 위치만 유지하며 하단 탭은 렌더링하지 않습니다.
- 설정은 내 산책 오른쪽 위에서만 진입하고, 알림 설정은 설정 안에 둡니다.
- 내 산책에서는 왼쪽 오늘의길 로고로 홈에 복귀합니다. 커뮤니티에서는 로고 또는 뒤로 버튼으로 복귀합니다.
- 커뮤니티는 기존대로 진입용 준비 화면만 유지합니다.


## 현재 미리보기: 하단 탐색 복원

- 홈·커뮤니티·내 산책 하단 탭을 복원하고 상단 중복 메뉴를 제거했습니다.
- 코스 생성/현재 위치와 추천 패널은 하단 탭 위에 배치합니다.
- 설정은 홈 우상단과 내 산책에서 진입하며 설정 화면에서는 하단 탭을 숨깁니다.
- 지도 타일 채도 78%와 390×844 데스크톱 비례 축소는 유지합니다.

## 산책 진행 목업

- 코스 카드의 `산책 시작`으로 진입하고, 우상단 초록 정사각형 아이콘으로 종료합니다. 설정 버튼은 옆에 유지합니다.
- 시간·걸은 거리·남은 거리를 하단 캡슐로 표시하고, 현재 위치 버튼은 캡슐 오른쪽 바로 위에 배치합니다. 상단 산책 상태·코스명 표시, 일시정지, 방향 안내 카드는 없습니다.
- 홈·커뮤니티·내 산책 탭과 설정을 오가도 현재 세션의 타이머와 경로는 유지됩니다.
- `/?preview=walk`는 예시 코스의 진행 화면으로 바로 진입하는 디자인 검토용 주소입니다.
- `/?preview=course`는 참고 이미지의 ‘조용한 산책’ 코스 확인 화면입니다. `산책 시작`을 누르면 같은 경로의 진행 화면으로 전환됩니다.
- 코스 확인 중에는 코스 생성 버튼 대신 카드 위에 현재 위치 버튼을 표시합니다. 이미지로 생성한 코스는 시작 전후 동일한 경로를 유지하며, 경로가 없는 예시는 코스 생성 패널로 연결합니다.
- 시간은 경과 시간이며, 거리와 현재 위치 이동은 예상 소요 시간에 따른 시뮬레이션입니다. 실제 GPS 추적은 하지 않습니다. 진행 중 세션은 새로고침 시 초기화되지만, 종료한 산책 기록은 이 기기에 저장됩니다.
- 카카오 SDK에 등록되지 않은 호스트(Tailscale IP 등)에서는 지도가 표시되지 않을 수 있습니다.


## 산책 기록과 커뮤니티

기존 홈·산책 진행 UI 및 **내 산책의 카드·통계·목록 배치**를 유지하고, 기록 클릭 후 여는 상세 화면과 커뮤니티 흐름을 추가했습니다.

- **산책 종료:** 종료 확인과 함께 시간·거리·걸은 구간의 좌표를 저장하고 완료 화면을 표시합니다. 추가 저장 단계 없이 ‘이 산책에 이야기 남기기’로 글을 쓰거나 ‘내 산책으로 돌아가기’를 선택합니다.
- **내 산책:** 기존 최근 기록과 전체 목록에서 경로 미리보기, 거리·시간·평균 페이스, 시작·종료 시각을 확인합니다. 별도의 일기·기분·사진 입력과 기록 수정 화면은 제공하지 않습니다.
- **커뮤니티:** 모두의 산책 / 내 이야기, 최신순 피드, 3개씩 더 보기, 글 상세, 작성·수정·삭제를 지원합니다. 팔로우·팔로워·팔로잉은 없습니다.
- **이야기 작성:** 기록의 ‘이 산책에 이야기 남기기’와 커뮤니티의 ‘이야기 쓰기’는 같은 작성 화면을 엽니다. 기록에서 진입하면 해당 코스를 첨부하고, 예전에 기록에 저장한 메모·사진이 있으면 가져옵니다. 새 글과 사진은 게시글에만 저장합니다. 본문은 최대 2,000자, 사진은 최대 5장이며, 코스 없이 작성할 수도 있습니다. 코스는 경로 좌표·거리·시간의 독립된 스냅샷입니다.
- **공개 범위:** 기록에서 시작한 이야기는 ‘나만 보기’, 커뮤니티에서 새로 쓰는 이야기는 ‘전체 공개’가 기본값이며 작성 화면에서 변경합니다. 전체 공개는 모두의 산책에, 나만 보기는 내 이야기에만 표시합니다. 비공개 저장 후 커뮤니티를 열면 내 이야기가 선택됩니다. 글 수정 시 기존 공개 범위를 유지하며 다른 작성자의 수정·삭제는 UI와 데이터 변경 함수에서 차단합니다.
- **저장:** `todaysroad-journal-v1` localStorage에 기록·게시글·사진을 저장합니다. JPG·PNG·WebP 사진은 입력당 최대 10MB이며 긴 변 1,200px 이하 JPEG로 변환합니다. 저장 공간 부족 시 입력 내용을 유지하고 재시도 안내를 표시합니다. 다른 탭의 저장 변경도 반영합니다.
- **목업 범위:** 예시 작성자와 고정된 로컬 사용자로 동작합니다. 서버·실제 인증·사진 업로드·실제 공개 게시·사용자 간 동기화는 없으며, 브라우저 데이터를 삭제하면 기기 내 기록도 사라집니다. 경로는 좌표 기반 도식이며 산책 진행의 거리·위치는 기존과 동일한 시뮬레이션입니다. 기존 통계의 기본값(12회, 18.4km, 4시간 32분)에 새 기록을 누적합니다.

| `lib/journal.ts`, `lib/useJournal.ts` | 기록·게시글 모델, 예시 데이터, 작성자 검사, 기기 저장 |
| `lib/photos.ts` | 사진 형식·크기 확인 및 저장용 변환 |

검증:

```bash
npm test          # 종료 구간 계산, 작성자 권한, 비공개 피드, 첨부 저장 등
npm run build     # Next.js 빌드 및 타입 검사
```

`http://localhost:8000/?preview=walk`에서 종료 버튼을 누르면 완료 흐름을 빠르게 확인할 수 있습니다. 홈의 ‘내 산책’ → 기존 예시 기록으로 상세·공유 흐름을, ‘커뮤니티’로 피드·작성 흐름을 확인할 수 있습니다.

## 경로 주변의 스팟 이야기

코스를 생성하거나 선택하면 위치와 이야기 근거를 확인한 후보 중 경로 100m 주변의 이야기를 최대 3개 제안합니다. 코스 카드·지도 마커·산책 중 ‘이 길의 이야기’에서 같은 상세를 읽을 수 있고, 닫으면 기존 산책 흐름으로 돌아옵니다. 스팟은 필수 경유지가 아니며 0개 코스도 정상적으로 시작할 수 있습니다. 출처·자료 기준·위치 확인 한계는 상세에서 확인합니다.

- 첫 후보는 광흥당, 공민왕사당, 독막로 176-1 건물입니다. 주소/장소 대표 좌표를 대조했으며 현장 출입구나 도보 접근성을 검증한 것은 아닙니다.
- `http://localhost:8000/?preview=spots`: 개발 전용 **가상 경로**와 위치 확인된 3개 장소로 시작 전 → 상세 → 산책 → 상세 → 종료 흐름을 검토합니다.
- `http://localhost:8000/dev/spots`: 개발 전용 콘텐츠 카탈로그. 경의선숲길 신수동 구간과 광흥창 터는 위치 미검증으로 표시하며 지도에 연결하지 않습니다.
- 기존 `/?preview=course`와 `/?preview=walk`에서는 스팟 0개 상태를 확인할 수 있습니다.
- 산책 기록·커뮤니티의 저장 구조나 방문 이력을 추가하지 않습니다. 코스 생성은 아래 이미지 기반 흐름을 사용하며, 산책 중 이동은 기존처럼 시뮬레이션입니다.
- 데이터 채택·보류 근거, 연결 규칙, 검증 명령과 제약은 [스팟 구현 기록](docs/spot-feature.md)을 참고하세요.

## 이미지 기반 코스 생성 (2026-09)

`코스 생성 → 추천 받기`를 지도 이미지 기반 파이프라인으로 교체했습니다. 현재 위치의 지도 캡처 → 길·자연·건물·아이콘 벡터 구분 → 전략 구성 → 카테고리 필터 → 경유지 선택 → 인식된 길 그래프 연결 → 실제 경로 길이로 코스 완성 순서입니다. 카카오 지도 타일과 픽셀/위경도 변환을 사용하며 도로·POI 검색이나 길찾기 데이터는 사용하지 않습니다.

- 개발 모드에서는 **로컬 Codex CLI의 기존 로그인**을 사용합니다. `codex login status`가 성공하면 별도 `OPENAI_API_KEY` 없이 실행할 수 있습니다. 분석은 OpenAI 서버에서 수행합니다. [.env.example](.env.example)을 참고하세요.
- 현재 위치 권한·타일 캡처·분석·경로 연결에 실패하면 임의 경로를 만들지 않고 재시도/조건 변경을 제공합니다. 고정 예시 코스의 미제공 경로도 타원으로 채우지 않습니다.
- 지도와 카드에서 경유지를 확인하고, 카드의 `지도에서 찾은 요소 보기`에서 캡처 이미지와 인식 결과를 겹쳐 볼 수 있습니다. 결과에는 실제 예상 시간, 되돌아오는 구간, 반영하지 못한 조건을 표시합니다.
- 범용 비전 모델의 벡터 추출을 이용한 프로토타입입니다. 전용 픽셀 세그멘테이션이나 전국 보행 정확도 검증을 완료한 구현은 아닙니다. 실제 모델 출력 검증은 API 키 연결 후 필요합니다.
- [실제 지도와 7단계 결과](http://localhost:8000/dev/image-route)에서 현재 위치 또는 서울·부산·제주의 공개 테스트 위치를 캡처하고 원본 지도·인식 요소·제외된 길·카테고리 후보·경유지·최종 코스를 확인합니다. 실패한 단계와 중간 결과도 유지합니다.
- 기존 산책 진행의 위치·거리 시뮬레이션과 기록/커뮤니티 저장 동작은 유지합니다. 이미지 분석 자료를 기록/게시글에 저장하지 않습니다.

[구현 단계·환경 설정·검증 및 제약](docs/image-route-generation.md)에 자세히 정리했습니다.
